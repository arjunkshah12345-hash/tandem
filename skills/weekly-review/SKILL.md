# Weekly review

## Collect
- Completed tasks in Tandem this week, plus executed approvals (emails sent, invoices chased, docs made).
- Calendar: meetings held this week; next week's commitments and deadlines.
- Sent mail: notable outcomes (deals closed, decisions made).
- Open tasks and anything that has waited on the user for more than three days.

## Write
```
## Week of Oct 20
**Done**
- Shipped onboarding flow (with Priya)
- Chased 4 overdue invoices — 2 paid ($3,400)
**Slipped**
- Brightline security overview — promised Oct 23, still not sent
**Next week**
- Mon: board prep due · Wed: Acme launch · Fri: payroll
**Suggestions**
- Block 2h Monday for board prep (calendar is full Tue–Thu)
```
Short bullets, real numbers. If the user asks for a team version, drop personal items and write in "we".
